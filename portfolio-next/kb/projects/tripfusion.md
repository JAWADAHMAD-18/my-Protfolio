## Overview
TripFusion is an AI-assisted travel platform for booking flights, hotels and custom packages with smart recommendations. It was Jawad's final year project. Live: https://tripfusion.vercel.app/

## What Jawad built
Token-based authentication with access and refresh tokens, Google OAuth, Redis, real-time chat with Socket.io, and a rule-based chatbot API. He also built a companion React Native (Expo) mobile app that uses the same backend as the web app.

## Stack
React, Node.js, Express, MongoDB, Redis, JWT, Google OAuth, Socket.io, React Native, Expo.

## Details
Project: TripFusion
Problem it solves: Planning a trip means juggling many sites for travel data and itineraries. TripFusion brings travel search and AI-assisted trip planning into one platform.
Hardest technical part: Pulling large datasets from a third-party travel API (Amadeus) and keeping the app fast. A Redis caching layer lets large responses load in seconds.
Solo or team: Solo, end to end
Timeline: About 2 months for the initial build (weekends, alongside university classes) as a final year project, improved afterwards
Supervisor feedback: "The UI and UX are both good, but the backend optimization is excellent. Even large API data loads within seconds, with good use of Redis." Dr. Akmal, FYP Supervisor, Department of Computer Science, IUB (permission granted)
